# 2026-09-24 交互流程回归

本轮围绕“画面与检测、录像图片回放、设置和按钮反馈”增加真实交互测试，使用 SQLite 内存库和临时视频，不操作生产媒体或数据库。

## 新增覆盖

| 操作 | 断言 | 修复前结果 |
|---|---|---|
| 单画面下点击另一通道，再恢复四画面 | 单画面显示当前通道，四画面恢复全部通道 | 失败：只改编号，仍显示旧通道 |
| 单画面下用键盘方向键换通道 | 列表选择与显示画面保持一致 | 失败：只监听鼠标点击 |
| 选择已经不存在的录像记录并播放 | 回放页可见“录像记录不存在” | 失败：消息写入隐藏监控页 |
| 定位三种保存设置控件 | 通道、录像、检测按钮具有独立对象标识 | 失败：三种保存按钮使用相同对象名 |
| 点击可见缩略图，点击跳转录像 | 发出该图片的 videoId 与 offsetMs | 通过，补齐可见界面路径覆盖 |
| Ctrl 取消最后一个缩略图选择 | 禁用导出/删除/回放，无旧记录回放信号 | 失败：隐藏表格仍选中旧记录 |
| 翻页后再次点击相同行号的缩略图 | 回放定位新页面的图片关联录像 | 通过，防止残留选择回归 |
| 模型路径不存在，继续预览，停止后重启 | 有明确模型消息，预览持续，停止后无新帧，重启有新帧 | 使用多帧短视频通过 |
| 单帧视频持续循环 | 多次输出帧且通道不报读取失败 | 失败：部分后端 EOF 后无法 seek |

补充连续操作回归：后台其他通道状态刷新不触发重新选择；Ctrl 多选后方向键移动焦点仍定位当前图片；真实 AVI 成功播放→选择缺失记录→再次正常播放时，停止旧视频并清除旧错误。
这三项在独立审查后均先复现失败，再通过修复验证。

## 修复

- 通道选择统一监听 currentItemChanged，单画面立即刷新布局及检测目标；后台列表刷新阻塞选择信号，避免误重载 YOLO。
- 图片缩略图选择和焦点变化共同同步记录；取消选择同步清除隐藏记录，禁止误用旧记录。
- 回放失败停止旧视频并在回放页显示原因，成功打开后更新当前录像提示。
- 通道/录像/检测保存控件使用独立标识，避免自动化误点。
- 文件 EOF seek 失败时重新打开同一文件并重试一次，不无限重试，也不影响摄像头流程。
