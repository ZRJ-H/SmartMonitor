# 智能监控系统需求验收记录

验收日期：2026年9月24日。依据为当天更新的《周睿杰 智能监控系统 合并需求与10天开发计划》，按“需求分析”中的 REQ-01 至 REQ-12 和验收标准逐项核对。

## 验收结论

**当前可以作为继续试用的开发版本，尚未达到整体交付验收条件。** 12项需求中，本机已核验范围通过3项，部分通过8项，未通过1项。这里的“部分通过”表示已证实一部分功能，但尚缺需求规定的现场、压力或完整流程证据，不代表这些功能一定有故障。

进度表中的开发阶段“已完成”不等于所有场景已经验收。例如四路预览的文件源自动测试通过，不能替代真实摄像头拔插和持续负载验收。

本轮没有修复产品代码、迁移生产数据库或更改生产配置。测试使用SQLite内存库、专用验收目录及生成媒体；未删除用户录像、图片或备份。按当前构建脚本执行了构建目录的依赖部署，没有继续修复此前暂停的部署校验逻辑。

## 已复现的验收缺陷

### 部署检查会将无效文件判为成功

调用方`deploy-runtime.ps1`已经传入`-CleanStart`，但`tests/verify_runtime_dependencies.ps1`没有声明和实现这个参数。当前脚本仅判断EXE和少数OpenCV文件是否存在，没有运行启动检查，也没有核对完整Qt/MinGW插件依赖。

本轮在专用验收目录放入3个纯文本文件，分别使用所需EXE和DLL名称，再调用检查脚本并传入`-CleanStart`。脚本仍输出PASS。这是确定的验收自动化缺陷，不能用全量构建报告中的成功状态证明独立部署通过。

这一项按此前指示保留待修，没有继续修改部署代码。本轮独立执行的清理PATH启动测试有单独证据，补足了本机启动检查，但不能消除脚本缺陷，也不能代替干净Windows验收。

### 交付二进制与当前构建不是同一份

用户`bin`程序SHA256仍为`FC303E2E154BC702B6643FEF2236BCA33062935F1D8432BD7B62188B005BA93D`，本次构建程序SHA256为`6E79D719D0057030B350079ED5678121A5E9E6DDC04E551958D77EE4F1DD7201`。前者是注册完成版本，后者含后续启动检查改动。本轮没有覆盖用户可执行文件，两个程序分别验收并分别留证，不能混用结果。

## 下一轮验收顺序

1. 完成部署校验，加入“缺Qt插件”“无效EXE”“缺QMYSQL运行依赖”负向用例；生成与当前测试基线匹配的完整目录，在干净Windows安装验证。
2. 接入实际摄像头及已配置模型，依次检查无人、有人、离开、重新进入、切换布局、退出登录；确认至少一次完整60秒事件及三图，并核对关联记录。
3. 在主界面完成查询→播放→暂停/倍速/拖动→截图→图片查看→关联回放→U盘导出，检查日志记录与导出内容；测试设置保存后重启。
4. 在隔离介质测试低磁盘、设备拔插、被占用和异常退出，不能直接填满系统盘或破坏生产媒体。
5. 按实际目标分辨率、来源数量及检测配置进行CPU、内存、帧率与交互延迟采样，然后完成7×24小时连续观察。短时测试不能替代一周结果。
