# 智能监控项目接管与带学入口

适用工程：C:/QtProjects/day20_smart_monitor。代码依据：16a7a30。
这是第 20 章工程的集成开发补充；原课程理论版、案例版均保留。
已有笔记说明你接触过相关课程，不据此认定你已掌握每项机制。

## 怎么用

第一轮只读 [90 分钟全貌与第一课](00-90分钟全貌与第一课.md)。
遇到看不懂的写法，再查 [C++与Qt写法拆解](01-C++与Qt写法拆解.md)。
第二轮按 [模块案例手册](20.Qt智能监控集成工程_结合案例复习总结.md) 追踪完整调用链。
随后完成 [动手任务与经验记录](03-动手任务与经验记录.md)，再进入
[工程管理与优化准备](04-工程管理与优化准备.md)。

建议节奏：先用约 90 分钟建立地图，再分 6～8 次、每次约 60～90 分钟带学。
时间是安排参考，能否进入下一步由你的解释和实验结果决定。
每次按“我讲一段 → 你复述 → 你动手 → 一起审查”的顺序进行。

## 这次学习的完成标准

| 能力 | 可检验的结果 |
| --- | --- |
| 找到代码 | 给你“图片无法跳回录像”，能指出需要查的 3 个位置 |
| 解释机制 | 能说明哪个函数在哪个线程执行、参数和对象何时失效 |
| 理解模块 | 能说清输入、输出、状态、依赖、失败处理 |
| 独立修改 | 自己完成至少 3 个小改动，各有测试和提交 |
| 工程判断 | 能用测量数据区分性能瓶颈和架构问题 |
| 项目陈述 | 根据实际参与记录讲清问题、选择、验证和仍有的边界 |

当前这些能力均为“待你验证”，文档已写完不代表你已学会。
最终项目介绍应如实区分课程基础、工具辅助实现、你亲手完成的验证和改进。
不编造独立从零开发经历；可以通过自己的修改、实验和取舍形成真实的项目经验。

## 每次交作业只需这几项

1. 我的理解：用 5～10 句话解释这一条链。
2. 我的改动或实验：文件、提交、命令、结果。
3. 我的证据：测试日志或实际输出。
4. 我还不确定的 1～3 个问题。

错误本身是学习材料。提交前先保留失败原因，不用把实验过程包装成一次成功。
